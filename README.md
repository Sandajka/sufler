# Суфлёр

Подсказчик эфиров и отыгровок для GTA RP (Windows).

**Скачать:** раздел [Releases](https://github.com/Sandajka/sufler/releases/latest) → `Sufler.zip`.
Распакуй в любую папку и запусти `Sufler.exe`. Программа сама сообщит, когда выйдет новая версия.

Проверь правила своего сервера про биндеры: обычно разрешена только отправка текста отыгровок.
